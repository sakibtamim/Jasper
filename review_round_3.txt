**<sub><sub>![P1 Badge](https://img.shields.io/badge/P1-orange?style=flat)</sub></sub>  Prevent zip slip during plugin extraction**

The installer shells out to `unzip` on untrusted archives without validating the contained paths (lines 33–37), so a crafted zip with entries like `../../../../etc/passwd` will write outside `src/plugins` before any manifest checks. That enables arbitrary file overwrite on the host when hitting `/api/plugins/install`. Sanitize entry paths or extract with a library that rejects `..` and absolute paths before writing files.

+import multipart from '@fastify/multipart';
+import fs from 'node:fs';
+import path from 'node:path';
